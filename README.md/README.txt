SocialSpace
==========

A polished React social-style interface.

Features:
- Login as Admin or Viewer
- Role-based access
- Admin can create posts
- Admin can delete posts
- Viewer has read-only access
- Live post count
- Responsive interface
- React useState

Run:
1. Extract ZIP.
2. Open the folder in VS Code.
3. Terminal:
   npm install
4. Then:
   npm run dev
5. Open the localhost URL shown by Vite.
